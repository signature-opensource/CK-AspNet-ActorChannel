# CK-AspNet-ActorChannel

[![Licence](https://img.shields.io/github/license/signature-opensource/CK-AspNet-ActorChannel.svg)](LICENSE)

**Deprecated.** The push to the connected actors is removed: tracking the live connections of the users across the
parties of a distributed application needs its own design. The packages of this repository are tombstones: a project
that depends on one of them fails to build with the `CKDEPRECATED` error.

| Package | Description |
|---------|-------------|
| [CK.AspNet.ActorChannel](CK.AspNet.ActorChannel/README.md) | Deprecated, without replacement. |
| [CK.Ng.AspNet.ActorChannel](CK.Ng.AspNet.ActorChannel/README.md) | Deprecated, without replacement. |

The generic WebSocket channel stays: [CK.AspNet.WebSocketChannel](https://github.com/signature-opensource/CK-AspNet/blob/stable/CK.AspNet.WebSocketChannel/README.md).
